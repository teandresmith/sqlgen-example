## Agent skills

### Issue tracker

Issues and PRDs live as local markdown files under `.scratch/<feature>/`.

### Triage labels

Uses the five canonical triage roles with their default strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`).

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root.
